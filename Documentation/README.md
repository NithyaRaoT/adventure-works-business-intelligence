# Project Documentation

This folder contains the technical documentation and business analysis supporting the Adventure Works Power BI project.

## Files Included

- **Data Model and Measures.pdf** – Explains the data model, table relationships, DAX measures, KPI calculations, and validation approach.
- **Business Insights.pdf** – Documents business questions, sales and profitability analysis, product performance, and reseller performance findings.

## Purpose

The documentation provides additional context on the dashboard design, analytical methods, and business logic used in this project.

## Tools Used

- Microsoft Power BI Desktop
- DAX
- Power Query
- Data Modeling
- Business Intelligence and Analytics

## Note

The project uses the Adventure Works sample dataset for learning and portfolio demonstration. Business insights and calculations should be validated against the source data before being used for decision-making.
